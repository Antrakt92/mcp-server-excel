# Contributing

Contributions to [ExcelMCP - Antrakt Fork](https://github.com/Antrakt92/mcp-server-excel)
target `main` through a pull request from a feature branch.

- [Contributor guide](docs/CONTRIBUTING.md): pinned SDK and native prerequisites,
  architecture, tests, review and submission.
- [AGENTS.md](AGENTS.md): repository rules and task-specific instructions for agents.
- [Fork build and verification](docs/fork/BUILD.md): portable package preparation.
- [Security policy](SECURITY.md): private vulnerability reporting and scope.

Keep customer workbook data, credentials, connection strings and private paths
out of public issues, pull requests and validation artifacts. Ordinary bug reports
belong in [the fork issue tracker](https://github.com/Antrakt92/mcp-server-excel/issues).
Preserve the original [MIT license](LICENSE) and [upstream attribution](FORK-NOTICE.md).
